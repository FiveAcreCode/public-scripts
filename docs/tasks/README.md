# Public Scripts task documents

Use this directory for bounded work orders when a task needs explicit baseline,
scope, exclusions, acceptance criteria, validation, external-action policy, and
handoff evidence. Small direct fixes do not require ceremonial task files.

Suggested name:

```text
YYYY-MM-DD-<short-topic>.md
```

A task document proves requested scope, not implementation, deployment, or
release. Keep durable product and architecture truth in their owning source and
documents.
