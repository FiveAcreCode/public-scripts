# Shopify Admin scripts

Public scripts that improve or extend the Shopify Admin experience without
forming part of a Shopify app. Shopify is a third-party platform; the scripts
in this area are independent and are not affiliated with, endorsed by, or
supported by Shopify.

## Script types

| Type | Contents |
|---|---|
| [Userscripts](userscripts/) | Browser userscripts installed through a compatible userscript manager |

Each type has its own catalog and usage requirements. Review a script's source,
site access, privileges, and data behavior before installing or running it.
