Install in three steps

A local fix, not another Shopify app.

The script changes only what your browser displays. It does not change your theme, store configuration, Shopify data, or staff permissions.

1

Install a userscript manager

Use Tampermonkey or another compatible userscript manager in your desktop browser.

2

Install Shopify Admin Tweaks

Open the install link and review its narrow Shopify Admin access before confirming.

3

Use the local toggle

Open the Five Acre Code control in Shopify Admin and switch the floating Sidekick prompt off or on.

What it can access

Small scope, stated plainly.

Browser userscripts execute on the pages they match. Review the complete source before installing any script on an authenticated admin page—including this one.

Page access

https://admin.shopify.com/* only.

Privileges

@grant none. No privileged Tampermonkey APIs.

Local storage

Saves only the panel and visibility preferences in your browser.
